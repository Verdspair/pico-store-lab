# Changelog

All notable changes follow [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and semantic versioning. The first public release is `0.2.0`.

## [0.2.0] - 2026-09-18

### Added

- Native Python, TypeScript, Rust, and Kotlin SDKs with shared contract fixtures.
- Rust Desktop CLI and Python CLI for the official PICO VRChat item.
- Kotlin-backed on-device Android client and bilingual release page.
- English/Chinese README and client UI, CI, contribution/security/release policies, and visual identity.
- Public Cloudflare release page at `pico.kanglives.top` with a daily D1-backed version check.

### Known limitations

- GitHub is the first artifact distribution channel; package registries and public APK mirroring are deferred.
- Android runtime behavior has not been validated on a connected headset for this release.
- Initial catalog tracks one native PICO item, VRChat.
