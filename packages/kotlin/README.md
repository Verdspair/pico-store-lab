# PICO Store Lab — Kotlin SDK

Android-compatible Kotlin protocol builders, response validators, and mirror policy. The PICO Android client includes this module directly. Maven publication is planned for a later release pass; the first source release is on GitHub.

For the complete on-headset sign-in, download, and install flow, see the [player guide](https://github.com/nkanf-dev/pico-store-lab#player-guide). The Android app is the runnable Kotlin SDK integration; this library alone does not install APKs.
